🙋 新手雷區與名詞釐清 FAQ

解答 2026 年新手最容易搞錯的 AI 核心概念，杜絕混亂！

完全不需要程式背景！MCP（模型上下文協議）是 Anthropic 推出的標準。它就像是一個「萬能橋樑」。以往 Claude 只是網頁瀏覽器，不能直接讀取你的電腦硬碟，或你日常登入的 Notion 軟體。而最新 Claude 桌面版 Cowork 只需一鍵「確認授權」，就能依據 MCP 規定的格式去安全讀寫你指定的本地資料夾與 Notion API 數據。
這是一個非常經典的新手痛點！

• Project (專案)：就像是一個「靜態背景規則包」。你上傳了你的品牌資料與大方向，Claude 會記住。但你每一次需要寫文案，還是得手動一步一步去詢問對話。

• Skills (技能)：就像是一部「動態的流程跑車」。平時完全不佔用任何 context 記憶體空間。只有當你在聊天中發送關鍵字觸發（例如輸入：多平台分發）時，它才會自動跳出來，把「選題、大綱、寫逐字、轉 Notion」一整套流程自動一次性跑完。
強烈建議新手與非技術人員，直接從 Claude Cowork 開始！

Claude Code 本質上是運行在黑色終端命令行介面（CLI）的開發環境，主要是為了工程師和程序開發者準備的。而 Claude Cowork 則是大眾版的桌面圖形介面應用，同樣具備 local 本地數據讀寫、自動生成完整網站的強大底層模型（3.5 Sonnet / 4.7 系列），但操作方式就像在聊 Line 或 Telegram 一樣直觀，無痛上手。
根據我們進行的 5 組相同提示詞正對面並排 PK 測試：

• Google Veo 3.1：在細節把控、物理慣性處理、手部逼真程度（例如用鋼刀切烤牛肉纖維）以及情感表達（瞪大雙眼喜劇英短貓）方面以 3:2 的比分獲勝，畫面真實感與細節首選。

• Sora 2：在「大範圍複雜人體動作（如滑板高難度旋轉失敗落地）」的動態流暢度、光線反射、以及帶有中文字幕配音與影片持續長度方面更佔據優勢。

一般情況下推薦新手優先在 Google Gemini Advanced 中試用 Veo 3。
